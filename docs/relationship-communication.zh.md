# 多人关系与沟通

制作人可以同时与多位角色发展恋爱关系。角色根据人设和相处经历决定接受、犹豫或拒绝，不能全部默认同意或默认要求唯一恋人。沟通和相处应逐步影响态度，但不保证最终接受。

正常说明感情、澄清交往对象、邀请多人出游不自动构成冒犯；明确欺骗、背弃已确认承诺、侮辱或强迫仍按具体语境处理。角色可以吃醋，但不能把自己上一轮的不安当成用户本轮再次冒犯的证据，累积惩罚。

按照用户明确说出的人数和成员回应，澄清后更新理解；不自行增加同伴或编造答应出游的条件。制作人与两人交往，不代表那两人互相交往。

对名字近音、口语重复和断句错误结合上下文理解，不确定时简短询问，不将转写误差当作冷落。

实现：`backend/src/eidolon/relationship.py` 的共同说明同时送给角色对话模型和判断模型，后者另有关系说明与操纵的区分规则。文字与通话共用对话引擎，不修改好感数值、历史记录或角色文件。

离线测试只能验证说明确实进入请求和现有流程保持正常，不能证明真实模型每次都会正确理解。实聊需覆盖：三人邀请后纠正成员、坦诚表达喜欢两位角色、询问她的顾虑并安抚、角色保留拒绝、明确侮辱或强迫的对照场景。现存历史中的误会不会被删除。
